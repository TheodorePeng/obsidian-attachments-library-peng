# 1.3.0：属性驱动的附件画廊

用户已批准的实施计划，执行日期 2026-10-25。插件 ID、最低版本 1.13.1、al_schema 1 和附件关联协议不变。

## 展示与配置

四个已有管理模式复用同一响应式网格；尊重 Bases 的查询顺序、分组和原生 Properties。使用 getOrder、getDisplayName、entry.getValue 与 Value.renderTo。封面→所选属性，移除重复标题、说明、长计数、固定路径/状态及额外 Keep。常态工具栏仅选择、刷新引用、更多；选中后才出现选择计数和安全删除。分页有需求才显示，并避让底部状态栏。

默认卡片宽 240（160–480）、间距 12、内边距 8、封面 4:3 / contain、每页 60、显示属性标签、隐藏空值但保留 false 和 0。原生视图设置保存到各自 Base：封面开关独立配置，封面属性默认 note.attachment，可改为其他本地图片属性。音视频/PDF 使用类型图标，预览时才加载媒体。

保留旧视图类型、alpOwned、名称、筛选、排序、分组及明确 order（包括 []）。仅缺少 order 时，在打开库流程中备份原配置并原子核对后初始化文件名/创建时间/出处。不改业务笔记、不触发全库补建。

## 导航和编辑

封面、空白、名称点击统一打开当前卡片的索引；Command/Ctrl 或中键新标签。名称有独立标准悬浮来源，支持两种修饰键顺序、会话去重和节点复用；原附件预览/打开通过独立小按钮/菜单。普通属性链接遵循自身目标，选择/编辑不触发父卡片导航。笔记图片按钮的既有出处手势保持独立。

共享属性编辑服务以索引路径+属性标识定位。常用文本、数字、日期、日期时间、字符串列表和布尔属性可编辑；al_keep 作为可选普通属性。文件/公式/关联协议/派生字段只读，复杂类型从索引编辑。processFrontMatter 只改指定字段；并发属性变化、未保存 Markdown、目标身份变化、删除事务或停用会保护写入。输入校验失败保留草稿。草稿跨卡片重绘及视图切换保留，更多菜单可继续编辑；草稿存在会阻止对应索引删除。
