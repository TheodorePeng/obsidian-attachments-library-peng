## 最终行为

- 未关联默认 Base 时，选用已有文件和新建文件两种方式互斥；已关联时隐藏新建入口。新建只在 Vault 根目录进行，成功后绑定默认画廊，失败不会覆盖已有文件。
- Base 和索引目录输入使用官方 `AbstractInputSuggest`。选择候选只修改草稿，Apply 才保存；关闭设置页丢弃草稿。路径校验、错误提示及保存失败回退均已实现。
- 新索引平铺到指定目录，保留附件扩展名，仅冲突时追加 `(2)`、`(3)` 等序号。整批预览提前分配互不重复的路径，执行拒绝已过期目标。
- 已识别旧索引继续复用，修改目录不搬迁旧索引、不重写 Base。保留移动跟踪及关联保护。
- 新安装默认开启自动索引；已有安装保持有效设置。初始化事件不触发补建，开关开启不追溯历史附件，关闭取消排队中的自动创建任务。
