# Attachments Library Peng 1.2.0 实施约束

本轮在 1.1.0 上修正悬浮竞争、引用误报和管理入口。实际检查与部署结果另见本轮验收记录，不以本文件作为通过证明。

- 图标 Command 悬浮只指向索引；图片本体保持既有原图悬浮设置。左键当前索引、中键索引新标签、Command 点击出处，保留原生 Command 点击选项。
- 阅读模式使用图片嵌入之外的兄弟按钮；Live Preview 使用编辑器覆盖层，不包装 CodeMirror 图片节点。悬浮只有一个标准来源、按会话去重，支持先按键和后按键，不修改 Hover Editor 或全局分发器。
- 图标右侧居中，20px 可见框、24px 命中区、14px 图形；图片进入时显示，120ms 淡入、200ms 延迟隐藏；键盘、触屏、减少动态效果可用。避免销毁渲染节点后复活旧图片。
- Markdown/Canvas 使用 mdast 与数学扩展解析；不把数学、代码和注释中的文本当链接。普通链接、引用式链接和 Wikilink 交给 Vault 上下文解析，原生缓存仍需新鲜。
- Base 公式仅做有限安全分析，不执行脚本：常量、属性、别名、if、link/image/file。按全部可能行分析；外链可证明不构成本地引用，本地目标计入，真正未知目标保持保护。属性变更重新分析 Base。
- 引用明细保留来源与位置；不确定原因携带受影响路径，无界原因才影响全部候选。有确定引用显示 used，检查完整度另列；orphan 必须完整且零引用。
- 排除自身自动属性、受控或可唯一识别的旧预览、Base 自动展示；普通笔记对索引的入链和真实正文业务引用必须保留。
- 标准打开命令按 alpOwned 找管理视图，不依赖名称。现有 Base 默认不写；新视图中文命名。配置整理需预览、备份、确认；被链接引用的旧名保留，原筛选以显式扩展方式保留。
- 原生/CMS 仅使用标准单项菜单与管理入口，不接管其批量选择或普通 Delete。专用视图默认60项分页，查询/索引/选择数量分开显示。
- 删除预览展示所有选中项，包括受保护项，列出全部索引、业务引用、自动关联排除、检查完整度及用户正文。无可执行项时确认禁用。
- metadata-only 只要求索引相关检查完整、无入链并通过保留/关联保护；pair 还要求原附件相关检查完整且零使用。无强制绕过。
- 确认后与每对执行前刷新检查，绑定相关引用和目标文件指纹，不以无关全局代次变化中止。事务内抑制自身派生写入，每个文件回收前再核对指纹，原件先于索引进入本地 .trash；保留日志与部分结果，不自动重试。
- al_schema 维持1，字段正文不迁移，Markdown变体/Base/Canvas仍不进入附件白名单。首次全库补建继续要求产品预览确认。
- 在 Obsidian AI Coding 做真实删除/恢复和主要交互验收；在 Math Peng 核对旧文件哈希、CMS与原生视图及 HE0.11.31共存。测试库HE0.11.28现有嵌入悬浮关闭，保持该设置；不升级其他插件。
- 基线155测试，四项覆盖率门槛90%保持。源码全部检查通过后，先测试库再Math，0700备份、哈希核对、只复制三个产物、保留data.json、定向重载与二次检查。不自动提交、推送或发布。
