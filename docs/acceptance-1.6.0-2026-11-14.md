# 1.6.0 本地实施与验收

日期：2026-11-14。源码基线 1.5.1，本地功能版本 1.6.0；插件 ID、最低 Obsidian 1.13.1 与 schema 1/2 协议保持兼容。未提交、推送或发布，未部署到原测试 Vault 或主 Vault。

## 实现结果

- Gallery 使用状态卡和单个连接对话框。Existing / New 表单互斥；Base 与视图一次保存，取消保留原连接。支持没有创建标记的兼容视图；新增视图需要预览及备份，不自动改写既有筛选。
- New index notes folder 使用输入草稿、候选、Save location / Cancel changes 及就地反馈。将 Base 文件误填为目录时明确说明类型错误，保留草稿与原设置。桌面端校验 Vault 内绝对路径并转换为相对路径；新目录按需创建。
- 任意位置的 schema 1/2 索引可重新识别。Restore existing library 发现旧候选，确认后只补 `al_schema: 1`。无标记候选在重复扫描时持续受保护，不会因运行时记忆自动变成已接管。
- 修复设置 URI、无资源 HTML 占位文字、重复普通 YAML 键和常见 Base 公式的误报。Base 表达式使用受限 AST，不执行 JavaScript；重复定义和无法确定的目标仍保守保护。解析器保留准确位置，也处理链接中的图片、引用式链接和裸本地 URI。
- 删除附件及索引时，先预览源文档精确变化；内存投影再次检查剩余引用，存在无法安全清理的引用则禁止执行。确认后备份二进制、索引和源文档，再逐文件核对身份及内容、清理引用、重新扫描并移到本地 `.trash`。
- 恢复记录有持久化阶段及完整性哈希。失败时先恢复目标文件，再按内容条件恢复引用；保留后续修改，冲突时报告 Recovery required。恢复入口位于 Maintenance & recovery。

## 真实 Obsidian 验收

环境：macOS，独立临时用户配置与 `ALP160 Isolated` Vault，Obsidian 1.13.7。只安装本插件运行产物。没有把完整原 Vault 或其他插件复制到隔离环境；Advanced URI 未安装时直接使用已有调试接口，没有自动安装。

统一部署脚本只允许固定的两个已有 Vault，所以隔离库使用受控复制 `main.js`、`manifest.json`、`styles.css`。源码产物与隔离安装副本三项 SHA-256 一致；原测试库安装清单仍为 1.5.1。

证据分层：

- 路径输入、候选方向键和 Enter 选择使用 Electron 原生输入事件，作用于真实 Obsidian 控件，不是回调 mock。
- 删除、恢复、接管的页面确认使用真实 DOM 控件的程序化点击；故障注入、重装和最终回归使用内部调试调用。这些操作确实执行了 Vault 写入、回收和恢复，但不等同于完整的操作系统鼠标端到端测试。
- DOM 状态、文件内容、SHA-256、`.trash` 清单及私有阶段记录证明数据结果；截图仅用于视觉检查。
