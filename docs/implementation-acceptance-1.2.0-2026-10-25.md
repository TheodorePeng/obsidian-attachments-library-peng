# Attachments Library Peng 1.2.0 本地实施与验收

日期：2026-10-25。源码：本仓库。插件 ID `attachments-library-peng`；最低版本仍为 1.13.1；数据协议 `al_schema: 1`。本轮实际运行环境已为 Obsidian **1.14.5**，与计划写作时的 1.14.4 不同；本轮没有升级 Obsidian 或其他插件。

## 实现结果

- 图片按钮在右边线居中，24px 点击区、20px 可见框、14px 图形、内移 4px；默认自动隐藏，120ms 淡入、离开延迟 200ms；支持键盘、触屏和减少动态效果。
- 阅读模式按钮与原生嵌入为兄弟；实时预览使用每个编辑器独立、挂载于文档 body 的固定覆盖层，由 CodeMirror 测量定位。覆盖层其他区域不接收鼠标事件。悬浮期间稳定触发点，结束或显式滚动、缩放后恢复跟随。
- 两个适配器共用悬浮控制器。按钮没有原生 `internal-link` 悬浮识别类，只有本插件注册的标准 `hover-link` 来源。非嵌入按钮的 mouseover 正常传递，让原生 Page Preview 取消之前排队的图片请求。普通点击、Command 出处、中键索引新标签保留；“原生 Command 点击”选项提供索引新标签行为。
- Markdown/math 语法树排除代码、数学和注释；Canvas 共用正文解析；自身自动属性、受控预览及可识别旧预览排除，真实业务入链保留。HTML 资源不能可靠解析时保护，包含 srcset、PDF object 与视频 poster。
- Base 使用有限表达式分析器和新鲜属性快照；无 eval、任意代码执行或 Bases 私有求值 API。记录引用位置和可解释问题，分开判断原附件与索引完整度。已知引用显示 used；完整且零引用才为 orphan。
- 管理入口按归属标记选择视图，保留旧名称和筛选；配置整理单独预览。工具栏解释查询条数、索引数和选择数。新增原生文件菜单安全入口，未接管 CMS 私有批量选择或 Delete。
- 所有删除入口使用结构化预览，保护项也显示全部索引、来源及原因。仅删索引和成对删除门禁分开；确认后比较相关安全快照和文件指纹；保持本地回收、串行顺序、日志与部分失败处理。

## 两个真实悬浮缺陷及修复依据

1. 在测试库实时预览中，Hover Editor 取得焦点会使编辑工具栏收起，图片位置上移 36px。若触发按钮跟着编辑器布局即时移动，会失去鼠标并关闭预览。独立固定覆盖层和悬浮触发点稳定机制解决此问题。
2. Math Peng 中，从图片进入按钮后再按 Command，原生 Page Preview 仍可能持有先前图片的等待按键请求。阻断按钮的所有 mouseover 会妨碍原生取消。移除原生链接悬浮识别并允许非嵌入事件传递后，等待完整延迟仅新增索引窗口。

上述调整没有修改 Hover Editor 源码、全局 trigger、其他插件设置，也没有强行关闭用户已有或钉住的窗口。验收记录比较本次新增窗口的文件目标，不以全部弹窗数量作判断。
